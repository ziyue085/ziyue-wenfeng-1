# 子曰文风 · ziyue-voice

把一个人的写作手法，拆成**可执行的规则**和**可运行的检查器**。

这不是文风模仿秀。它从 6 份本人亲手书写的原始材料（约 4,500 字可统计语料 + 6,000 字图片型长文）里，提取出 13 项量化基线、10 项风格指纹、6 组正反例逐句对照，做成一个 WorkBuddy Skill：**写之前能查规则，写之后能跑体检**。

---

## 一句话结论

> **用「我」的身体经验开头，用「可能」给自己留后门，用四字格砸重音，用一句问话收段，最后把个人小事放进土地和宇宙里稀释一遍。**

再补一句更本质的：

> 他写东西时其实在干一件很具体的事——**把一个说不清的感受，拆成能看见的东西，然后诚实地承认自己没拆干净。**

所以仿写的正确姿势不是「写得文艺」，而是**先看见，再承认看不见**。

## 十项风格指纹

1. **第一人称绝对优先** —— 每千字 31 次「我」，不写「我们应该」「人们往往」，普遍命题一律降格为个人经验。
2. **具体先行、抽象在后** —— 先记「谁在研究 AI、谁在打游戏」，再抽一句「这也算是对威压的一种拆解」。判断句永远在后，且只有一句。
3. **对事实硬，对归因软** —— 「亏了就是亏了」是硬的；「可能只是一粒尘埃」是软的。模糊只出现在预测与归因处。
4. **长短交替的呼吸** —— 78 字长句（7 顿，末端三层递减收）紧接 12 字三顿短句。
5. **文白夹杂但配比克制** —— 四字格 14／千字，只有掉书袋型写作者的一半。不是展示学问，是压节奏。
6. **用典自嘲** —— 引文 → 羡慕 → 模仿 → **失败**，四步缺一不可。引用不是论据，是审判自己的材料。
7. **排比用四项** —— 「实事求是，静坐欢心，临危不乱，灵活应变」。三项是公文节奏，他几乎不用。
8. **问句收段，常连问** —— 「为啥要这样呢？这是怎么形成的呢？太奇怪了，我根本无法理解。」问号是用来把判断悬置的。
9. **尺度升降作为止痛机制** —— 宇宙轴（地球是尘埃 → 我是尘埃）与土地轴（血肉化作苗，骨头化作秧）。
10. **收尾不结论** —— 承认毛病 → 给一个很小的自我命令 → 用「不知道」收住；长篇可加一首七律。

## 用法

```bash
# 体检一篇草稿（长随笔）
python scripts/style_lint.py --file draft.txt --mode long_essay

# 短札 / 观察清单
python scripts/style_lint.py --file note.txt --mode note

# 只输出机器可读指标
python scripts/style_lint.py --file draft.txt --json

# 打印紧凑版写作登记表
python scripts/style_lint.py --register
```

退出码 `1` = 存在硬伤（AI 味词 / emoji / Markdown 结构符号），必须改。
容差按字数缩放：<800 字放宽 25%，800-2000 字 15%，>2000 字 8%。

### 首稿通病（实测，三轮迭代得出）

按规则写第一遍，几乎必然出现四项偏离——不是内容问题，是漏了动作：

| 症状 | 首稿实测 | 修法 |
|---|---|---|
| 句子太碎 | 逗号／句 0.83（基线 1.4+） | 相邻两句合成一句 40 字长句，句号只留段末 |
| 全无文言 | 文言虚词 0.0（基线 8+） | 「而／亦／未／之／皆」替换白话连接 |
| 无长句 | 长句占比 0%（基线 8%+） | 每 400 字至少一句 40 字以上 |
| 无比喻 | 比喻标记 0（基线 1.5+） | 加一个「好似／宛如」＋身体或自然意象 |

改一遍通常从 10 项偏离降到 0-3 项。

## 方法本身（可复用的四步）

1. **严格口径选语料** —— 只收可确认为本人亲手书写的原始材料，剔除一切助手整理稿。否则会蒸馏出助手的文风。
2. **先量化再定性** —— 句长分布、标点密度、词表命中率先跑出来，再谈「风格」。凭印象提炼一定会失真。
3. **正负例对照** —— 同一层意思写两版，把差异拆成可执行的「刀」。
4. **闭环验证** —— 按规则写一段，跑体检，改到通过。**第一稿通常有 10 项偏离**，这个过程本身就是规则有效性的证明。

## 边界

- 只覆盖**随笔／札记**，不覆盖公文、学术论文、商业文案、公开演讲。这四类他必然另有一套写法，但本语料没有样本，**不做推演**。
- 语料仅 6 份、时间跨度 4 个月（2026-06～10），无法判断这是稳定风格还是阶段性状态。
- 全部为私密写作（自部署 Memos + 个人随笔），内省强度可能高于公开发表时的常态。
- 长篇为图片型 PDF，人工转录，个别字可能有误；统计以句法结构为主，不受单字影响。

**若要提高精度，最值得补的语料**：公考申论或课程论文 2-3 篇（覆盖公文体）、更早期的文字（高中作文/日记）、微信朋友圈等半公开文本。
