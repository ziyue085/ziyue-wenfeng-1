# 子曰文风 · ziyue-voice

一句话安装（WorkBuddy 用户）：

```bash
git clone https://github.com/ziyue085/ziyue-wenfeng-1.git ~/.workbuddy/skills/ziyue-voice
```

装完后在对话里说「用我的风格写」「把这段改成我的口吻」即可触发。不是 WorkBuddy 环境也没关系，直接读 `SKILL.md`，规则不依赖任何工具。

把一个人的写作手法，拆成**两层规则**和**一个能自己承认边界的检测器**。

这不是文风模仿秀。它从 6 份本人亲手书写的原始材料（约 4,476 字可统计语料 + 约 6,000 字图片型长文）里提取表层参考带，做成一个 WorkBuddy Skill：**写之前能查原则，写之后能跑检测，但检测通过不等于像。**

> **v2 说明（2026-10-23）**：修复了检测器的 7 处统计缺陷，把「必须怎么怎么写」的硬性配方降级为「核心原则 + 可选特征」，并补上 46 项回归测试与一份独立评估方法。旧版「四字格 14/千字」是错误口径，真实值约 6/千字——详见下文。

## 一句话结论

> **用「我」的身体经验开头，把说不清的感受拆成能看见的东西，然后诚实地承认自己没拆干净。**

再补一句：这个声音的核心不是「文艺」，是**先看见，再承认看不见**。

但两句都是描述，不是配方。真正可执行的是下面两层。

## 两层规则

**核心原则（必须）**：具体经验先行、判断在后｜个人视角不替群体下结论｜事实用确定句、归因用推测句｜长短句自然变化（不设配额）｜允许真实的不知道｜从场景提炼判断。

**可选特征（按需）**：「可是」单用转折｜文白夹杂与四字格｜用典后自嘲｜自然与身体意象｜问句收尾｜概率化措辞｜清单式罗列。

可选特征**不得为匹配指标强行添加**。任何一项被机械复用都会立刻变假。

## 检测器能做什么、不能做什么

**能可靠检查**：分体裁的硬伤（长随笔的 Markdown／emoji、随笔里的行话）、句长分布、标点密度、第一人称去重频率、固定四字表达密度（词表只收四字）、强比喻标记数、套话分级。

**只作提示、不判失败**：省略号、书名号、感叹号、「综上所述／由此可见／毋庸置疑」类语体套话——个人偏好不是正确性标准。

**不能可靠检查**：读起来像不像、思路是否连贯、用典是否恰当、内容是否准确。

> `PASS` 只说明表层接近。**它不是风格验证成功。** 真正的验证见 [`EVALUATION.md`](EVALUATION.md)。

## 用法

```bash
# 检测表层特征
python scripts/style_lint.py --file draft.txt --mode long_essay
python scripts/style_lint.py --file note.txt  --mode note
python scripts/style_lint.py --file draft.txt --json
python scripts/style_lint.py --register

# 跑测试
python -m unittest discover -s tests -v
```

**退出码三态**：

| 码 | 含义 | 处理 |
|---|---|---|
| 0 | 通过：无硬伤、无提示 | 仍需人工读一遍 |
| 1 | 硬伤：**该体裁下**确定不该出现的元素 | 必须改 |
| 2 | 提示：标点偏好、语体性套话、区间偏离 | 逐条人工判断，不要机械修 |

硬伤按体裁判定：`long_essay` 含 Markdown／emoji／行话；`note` 只含行话；`generic` 无硬伤，全部降为提示。

`--mode generic` 用于非随笔文本：不做区间比对（没有该体裁语料，不拿随笔基线去量别体），只检查硬伤与提示。

容差按字数缩放：<800 字 25%，800–2000 字 15%，>2000 字 8%。

### 首稿通病（实测）

按规则写第一遍，通常仍会偏离——但**偏离不等于错**，先判断是不是内容真的缺了东西：

| 症状 | 首稿实测 | 应先确认 |
|---|---|---|
| 固定四字表达过少 | 1.56/千字（参考带 3–12） | 是不是真需要成语？不需要就不加 |
| 无长句 | 长句占比 0% | 是不是全篇节奏过平？ |
| 无文言 | 文言候选字 0 | 是不是写得过于口语？ |
| 无问句 | 问句率 0 | 判断是否真的已经想清楚了？想清楚就不用问 |

**不要照着表格填空**，那是把描述当配方。

## 评估（重要）

本项目严格区分四层：

1. **表层特征是否接近基线** —— 已有自动化检测。
2. **读起来是否像本人** —— 需人工盲测，**尚未执行**。
3. **是否保留了思考过程** —— 需逐段人工标注，尚无量化方法。
4. **内容是否准确自然** —— 需人工通读与核查，**尚未执行**。

盲测流程与记录模板见 [`EVALUATION.md`](EVALUATION.md)。**本项目没有虚构的实验数据；所有未做过的测试都标注为未做。**

## 方法（可复用的四步）

1. **严格口径选语料** —— 只收可确认本人亲手写的材料，剔除助手整理稿，否则会蒸馏出助手的文风。
2. **先量化再定性** —— 句长、标点、词频先跑出来，再谈风格。凭印象提炼必失真。
3. **正负例对照** —— 同一层意思写两版，把差异拆成可执行的动作。
4. **闭环但不过度** —— 写完跑检测，改到合理即停；**不以 PASS 作为成功标准**。

## 边界

- 只覆盖**随笔／札记**。不覆盖公文、申论、学术论文、商业文案——没有样本，不做推演。
- 语料 6 份、时间跨度 4 个月（2026-06～10），无法判断是稳定风格还是阶段性状态（该时期本人自述处于低谷）。
- 全部为私密写作，内省强度可能高于公开发表时的常态。
- 长篇为图片型 PDF 人工转录，个别字可能有误；统计以句法结构为主。
- 所有词表均为**封闭候选表**，命中数不等于语法分析结果。

若要提高精度，最值得补的语料：申论／课程论文 2–3 篇、更早期文字、朋友圈等半公开文本。
